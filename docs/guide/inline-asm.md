# インラインアセンブラと手書き .asm

`mincc` の C サブセットから外れたことをやりたいときの2つの逃げ道です。

## `asm("...")` 文

文字列の中身を**そのまま** `mincasm` へ流し込みます。

```c
char [[address = 0x05]] PORTA_DIR;

char main() {
    PORTA_DIR = 0xFF;
    asm("mvi r0,0x5A\n"
        "stm 4,r0\n");     /* PORTA(0x04) へ直接書き込む */
    return 0;
}
```

### 書き方の決まり

- **文であって式ではありません。** `char x = asm("...");` はエラーです。
- C と同じく**隣接する文字列リテラルは連結**されます。
  1命令1行で書けるので読みやすくなります。
- `mincasm` は行指向なので、複数命令は `\n` で区切ってください
  （末尾に `\n` がない場合はコンパイラが補います）。
- 使えるエスケープは `\n` `\t` `\r` `\\` `\"` `\'` です。
  **`\0` は使えません**（内部で NUL 終端文字列として扱うため）。
- ラベルや `;` コメントもそのまま `mincasm` に渡るので使えます。

```c
asm("loop:\n"
    "  mvi r0,1\n"
    "  jr loop\n");        /* ラベルも書ける */
```

### オペランドの結び付けはありません

GCC の `asm(... : "=r"(x) : "r"(y))` に相当する機能は**ありません**。
C の変数を名前で参照することはできません。

値をやり取りするには `[[address = N]]` 付きのグローバル変数を使います。

```c
char [[address = 0x0200]] scratch;

char main() {
    scratch = 3;
    asm("ldm r0,0x0200\n"
        "add r0,r0\n"
        "stm 0x0200,r0\n");
    return scratch;         /* 6 */
}
```

### レジスタの扱い

レジスタの保全は**書き手の責任**です。ただし:

- **`r0` と `r1` は文の境界では常に空いています。** 自由に使って構いません
  （`sei()`/`cli()` の実装もこれを利用しています）。
- `r2` 以降は式評価中の値が乗っている可能性があります。文の境界であっても、
  `mincc` がどこまで使っているかは自明ではないので、触るなら `push`/`pop` で
  囲んでください。
- `r14:r15`（Y）はフレームポインタです。**壊すと関数から戻れなくなります。**
- `r12:r13`（X）はグローバル変数アクセスのたびに作り直されるので、
  跨いで保持されることはありません。

`asm(...)` はレジスタスタックにも型システムにも一切触れません。
値を返さないので、式の中には置けません。

## `sei()` / `cli()`

同じ仕組み（内部的には `ND_ASM` ノード）で実装された組み込み関数です。

```c
sei();   /* ldm r0,2 / mvi r1,2   / or  r0,r1 / stm 2,r0 */
cli();   /* ldm r0,2 / mvi r1,253 / and r0,r1 / stm 2,r0 */
```

`PSR`（データアドレス `0x0002`）のリード・モディファイ・ライトです。
`[[address=0x02]] psr; psr = 2;` と直接書く方法と違って、
**キャリーフラグ（bit0）が保存されます**。

他に同名の宣言がないときだけ組み込みとして解釈されるので、
`char sei = 5;` と書けばそちらが優先されます（`asm` は本物の予約語なので
シャドウできません）。

## 全部アセンブリで書く

`mincc` を通さず、`mincasm` に直接 `.asm` を食わせられます。

```sh
./target/mincasm < myprog.asm > verilog/program.hex
```

文法は [toolchain/mincasm.md](../toolchain/mincasm.md)、命令の意味は
[cpu/isa.md](../cpu/isa.md) を参照。

### 最小の骨格

```asm
        .org 0x0000
start:
        mvi r0,0xFF
        stm 5,r0        ; PORTA_DIR = 0xFF
        mvi r0,0x55
        stm 4,r0        ; PORTA_OUT = 0x55
        halt
```

### 手書きするときの注意

- **SP はリセット時 `0x0000`** です。`push` はプリデクリメントなので、
  最初の push は `0xFFFF` に書かれます。そのまま使って構いませんし、
  `stm 0,rN` / `stm 1,rN` で好きな位置に初期化しても構いません。
- **C フラグは限られた命令でしか定義されません。**
  `add`/`adc`/`sub`/`sbc`/`rr`/`lt`/`ltc` 以外を挟むと壊れます。
  多バイト演算は連続で並べてください。
- **ゼロフラグはありません。** ゼロ判定は `chz` で 1/0 の値を作り、
  それを `jz` にかけます。
- `Y`（`r14:r15`）をフレームポインタにするのは `mincc` の規約であって
  ハードウェアの決まりではありません。手書きなら自由です。
- 絶対アドレッシングが届くのは `0x0000`–`0x03FF` だけ、
  ペア相対の変位は `-32`〜`+31` だけです。

### 割り込みハンドラを手書きする

```asm
        .org 0x0000
        jr   start
        .org 0x0001
        jr   isr0            ; irq_in[0]
        .org 0x0002
        reti                 ; 未使用スロットは reti で埋めておくと安全
        .org 0x0003
        reti
        .org 0x0004
        reti

        .org 0x0005
start:
        ldm  r0,2            ; PSR を読んで
        mvi  r1,2
        or   r0,r1
        stm  2,r0            ; IE を立てる（= sei()）
main_loop:
        jr   main_loop

isr0:
        push r1              ; 使うレジスタは全部自分で退避する
        push r0
        ...
        pop  r0
        pop  r1
        reti                 ; ret ではなく reti
```
