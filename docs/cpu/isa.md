# minc 命令セットリファレンス

対象: `verilog/minc_h.sv` のデコーダと `mincasm/main.c` の `g_inst_specs[]`。
この2つが実装上の正であり、本ドキュメントはそこから起こしたものです。

> パイプライン版 `minc_p2.sv` / `minc_p5.sv` は**このオペコードマップに追随していません**。
> [known-issues.md](../known-issues.md) を参照。

## 命令語の形

命令語は **18ビット固定長**（`instr[17:0]`）です。
`mincasm` は1命令を5桁の16進数1行として出力し、Verilog 側が `$readmemh` で読みます。

上位ビットだけでクラスが決まるよう配置されています（デコーダを1回で済ませるため）。

### 第1階層: `instr[17:16]`

| `instr[17:16]` | クラス |
|---|---|
| `00` | ALU / 即値 / スタック（`instr[17:14]` でさらに分岐） |
| `01` | メモリ（`stm` / `ldm`） |
| `10` | `calr` |
| `11` | `jr`（`halt` は `jr -1`） |

### 第2階層: `instr[17:14]`（`instr[17:16] == 00` のとき）

| `instr[17:14]` | グループ |
|---|---|
| `0000` | ALU グループ（機能は `subop = instr[13:10]`） |
| `0001` | **未使用**（空き） |
| `0010` | 即値グループ（`mvi` / `decs` / `jz`） |
| `0011` | スタックグループ（`ret` / `reti` / `push` / `pop`） |

## ALU グループ

```
instr:  0000 ssss ss.. dddd rrrr
        ^^^^ ^^^^^^    ^^^^ ^^^^
        |    subop     rd   rs
        instr[17:14]=0000
```

- `subop` = `instr[13:10]`
- `rd` = `instr[7:4]`（第1オペランド。書き込み先でもある）
- `rs` = `instr[3:0]`（第2オペランド）
- `instr[9:8]` は未使用（`mincasm` は 0 を書く）

| ニモニック | subop | 動作 | C フラグ |
|---|---|---|---|
| `mov rd,rs`  | `0000` | `rd = rs` | 不定 |
| `or rd,rs`   | `0001` | `rd = rd \| rs` | 不定 |
| `and rd,rs`  | `0010` | `rd = rd & rs` | 不定 |
| `xor rd,rs`  | `0011` | `rd = rd ^ rs` | 不定 |
| `add rd,rs`  | `0100` | `rd = rd + rs` | キャリーアウト |
| `adc rd,rs`  | `0101` | `rd = rd + rs + C` | キャリーアウト |
| `sub rd,rs`  | `0110` | `rd = rd - rs`（= `rd + ~rs + 1`） | `!borrow` |
| `sbc rd,rs`  | `0111` | `rd = rd + ~rs + C`（= `rd - rs - 1 + C`） | `!borrow` |
| `rr rd,rs`   | `1000` | `rd = {C, rs[7:1]}`（キャリー経由の右ローテート） | `rs[0]` |
| —            | `1001` | **予約**（`rr` と同じアームに落ちる。使わないこと） | `rs[0]` |
| `lt rd,rs`   | `1010` | `rd = (rd < rs) ? 1 : 0`（符号なし比較） | 結果と無関係（`rs[0]`） |
| `ltc rd,rs`  | `1011` | `rd + ~rs + C` に借りが出れば `rd = 1`、なければ `0` | 結果と無関係（`rs[0]`） |
| `chz rd,rs`  | `1100` | `rd = (rd == 0) ? 1 : 0` — **`rs` は無視される** | 不定 |
| —            | `1101` | **未定義**（結果は `x`） | 不定 |
| `mul rd,rs`  | `1110` | `rd = (rd * rs)[7:0]` | 不定 |
| `mulh rd,rs` | `1111` | `rd = (rd * rs)[15:8]` | 不定 |

### 使いかたの要点

- **「Cフラグ不定」は本当に不定です。** RTL では `carry_flag_next = 1'bx` を
  そのまま `PSR[0]` に書きます。`mov` を1つ挟んだだけでキャリーは失われるので、
  多バイト演算は `add`/`adc`、`sub`/`sbc` を**連続で**並べてください。
- **ゼロフラグはありません。** `x == 0` は `chz` で 1/0 の**値**を作り、
  それを `jz` で分岐に使う、という流れになります。
  ゆえに `chz` を2回かけると「0以外なら1」（論理否定の否定）になります。
- **16bit の大小比較**は `sub`（下位）→ `ltc`（上位）の2命令で行います。
  `sub` が下位バイトの借りを C に残し、`ltc` がそれを引き継いで
  16bit全体の借り＝`<` の結果を作ります。8bit なら `lt` 1命令です。
- `chz` の第2オペランドは無視されますが、`mincasm` は2オペランドを要求するので
  慣習的に `chz r2,r2` のように同じレジスタを書きます（`mincc` もそうしています）。

## 即値グループ（`instr[17:14] = 0010`）

即値は命令語の中で**2つのニブルに分割**されています。

```
imm8 = { instr[11:8], instr[3:0] }
```

```
instr:  0010 xx nnnn dddd nnnn
             ^^ ^^^^ ^^^^ ^^^^
             |  imm8 rd   imm8
             instr[13:12]
```

| ニモニック | `instr[17:12]` | 動作 |
|---|---|---|
| `mvi rd,n` | `001000` | `rd = n`（8bit即値） |
| `decs n`   | `001001` | `SP = SP - n`（`instr[7:4]` は 0） |
| `jz n,rs`  | `001010` | `rs`（= `instr[7:4]`）が 0 なら `PC = PC + 1 + signed(n)` |
| —          | `001011` | **未使用**（空き） |

- `mvi` の即値は `mincasm` 上 `-128`〜`255` を受け付けます（負値は2の補数で格納）。
- `decs` の即値は `0`〜`255`。`SP` を n だけ**下げる**（スタックは下方向に伸びる）ので、
  スタックフレームの確保が1命令で済みます。
- `jz` の変位は符号付き8bit（`-128`〜`127`）。基準は**次の命令**です
  （`PC` は `S_DECEXEC` で既に +1 されている）。
  `mincasm` にラベルを渡せば自動で相対値に変換されます。

**分岐は `jz` 1つだけ**です。「等しければ」「大きければ」といった条件は、
ALU で 1/0 の値を作ってから `jz` にかける、という形で表現します。

## スタックグループ（`instr[17:14] = 0011`）

| ニモニック | `instr[17:12]` | 動作 |
|---|---|---|
| `ret`  | `001100` | `PC = pop16()` |
| `reti` | `001101` | `ret` と同じ。加えて `PSR = PSR_SHADOW` |
| `push rs` | `001110` | `SP -= 1; mem[SP] = rs`（`rs` = `instr[7:4]`） |
| `pop rd`  | `001111` | `rd = mem[SP]; SP += 1`（`rd` = `instr[7:4]`） |

- スタックは**下方向に伸びます**（プリデクリメント push / ポストインクリメント pop）。
- リセット直後 `SP = 0x0000` なので、最初の `push` は `0xFFFF` に書きます。
- `calr` は戻り先アドレスを**上位バイト → 下位バイト**の順に push します
  （結果として下位バイトが低いアドレス側に置かれる = リトルエンディアン）。
  `ret` はそれを下位 → 上位の順に読み出します。
- `reti` については [interrupts.md](interrupts.md) を参照。

## メモリグループ（`instr[17:16] = 01`）

`instr[15]` がアドレッシングモード、`instr[14]` がロード／ストアを選びます。

| `instr[17:14]` | 命令 | 形式 |
|---|---|---|
| `0100` | `stm rp+n,rs` | レジスタペア相対・ストア |
| `0101` | `ldm rd,rp+n` | レジスタペア相対・ロード |
| `0110` | `stm n,rs`    | 絶対アドレス・ストア |
| `0111` | `ldm rd,n`    | 絶対アドレス・ロード |

### レジスタペア相対 `rp+n`

```
instr:  01 s 0 nnnnnn dddd pppp
                ^^^^^^ ^^^^ ^^^^
                変位   データ ペア基点
```

- `n` = `instr[13:8]`、**符号付き6bit**（`-32` 〜 `+31`）
- データレジスタ = `instr[7:4]`
- ペア基点 = `instr[3:0]`。**偶数**でなければならない
  （`mincasm` が偶数以外を弾く）。ペアは `{r(p+1), r(p)}`、`r(p)` が下位バイト
- 実効アドレス = `{r(p+1), r(p)} + signed(n)`

アセンブリでの書き方（すべて同じ命令になります）:

```asm
ldm r2, Y-1        ; Y = r14:r15 の別名
ldm r2, rp14-1     ; ペア基点をレジスタ番号で書く
ldm r2, r14-1      ; "rp" は省略可
stm X+0, r3        ; X = r12:r13
```

**変位が6bitしかない**のがローカル変数フレームの制約になります。
`mincc` はフレームが `[-32, 31]` を超えるとコンパイルエラーにします
（黙って切り詰めない）。

### 絶対アドレス

```
instr:  01 s 1 nnnnnn dddd mmmm
                ^^^^^^ ^^^^ ^^^^
                addr下位 データ addr上位
```

- アドレス = `{instr[3:0], instr[13:8]}` の **10bit**（`0` 〜 `1023`）
- データレジスタ = `instr[7:4]`

```asm
stm 0x04, r2       ; PORTA へ書く
ldm r3, 2          ; PSR を読む
```

絶対アドレスが 10bit しかないため、**グローバル変数とMMIOは 0x000〜0x3FF に
収まっていなければなりません**。`mincc` はグローバル変数を `0x100` から
割り当てます（[memory-map.md](memory-map.md)）。

## 相対分岐 / 呼び出し

| ニモニック | `instr[17:16]` | 動作 |
|---|---|---|
| `calr n` | `10` | `push16(PC + 1); PC = PC + 1 + signed(n)` |
| `jr n`   | `11` | `PC = PC + 1 + signed(n)` |

即値は16bitで、ニブルが**入れ替わって**格納されています。

```
imm16 = { instr[15:12], instr[7:4], instr[11:8], instr[3:0] }
          ^^^^^^^^^^^^  ^^^^^^^^^^  ^^^^^^^^^^^  ^^^^^^^^^^
          imm[15:12]    imm[11:8]   imm[7:4]     imm[3:0]
```

一見奇妙ですが、**下位8bitの取り出し位置が即値グループ（`mvi`/`jz`）と同一**
（`{instr[11:8], instr[3:0]}`）になるように配置されており、デコーダの
配線を共有できます。

### `halt`

```
halt = 0x3FFFF = jr -1
```

自分自身へ無限ジャンプする擬似命令です。`mincasm` は固定語として出力します。
シミュレーション時（`SIM` 定義時）は `$finish` します。

## 削除された命令

過去のドキュメント・アセンブリに出てくることがありますが、**現在は存在しません**。

| 命令 | 状況 |
|---|---|
| `stf` / `clf` | フラグ操作命令。どのコアも実装していなかったため `mincasm` からも削除。旧エンコーディング `0x08`/`0x09` は現在 `mvi`/`decs` なので、残っていると**別の命令として実行されます**。フラグ操作は `PSR`(`0x0002`) への `stm`/`ldm`、または `mincc` の `sei()`/`cli()` で行ってください |
| `adi` / `adic` | 即値加算。`mvi` + `add` で置き換え済み |
